# Amazon Sales Analysis Dashboard

## Project Summary
This is a Power BI dashboard built to analyze Amazon sales performance. It converts raw sales data into easy-to-understand visual insights like total revenue, order volume, product trends, and regional performance.

## Key Features
- Sales Performance: Overview of total revenue, total orders, profit margins, and average order values.
- Trend Analysis: Visual breakdown of sales by day, month, and year to track performance over time.
- Category Breakdown: Identification of top-performing products and sales by category.
- Geographic Insights: Sales distribution mapped across different locations.

## Tools Used
- Microsoft Power BI Desktop
- Power Query (Data cleaning and transformation)
- DAX (Data Analysis Expressions for custom metrics)

## File Contents
- Amazon_Sales_Analysis.pbix (Main Power BI dashboard file)
- README.md (Project documentation)

## How to Run the Project
1. Install Power BI Desktop on your computer.
2. Download or clone this repository.
3. Open the file named Amazon_Sales_Analysis.pbix in Power BI Desktop.
